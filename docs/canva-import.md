# Canva import handoff

## Import this file

Use `output/Rentify_UniPreneur_Canva_Import.pptx` in Canva. It is a 13-slide, 16:9 PowerPoint file made from editable text boxes, basic shapes and images. Slide 11's competitor grid uses separate text and shape elements instead of a native PowerPoint table, so its labels and cells can be refined individually after import. Slide content uses Arial.

In Canva, upload the `.pptx` and open it as a presentation. After conversion, check slides 4, 9 and 11 for image placement, portrait order and table alignment. Canva may adjust imported formatting or substitute fonts; correct any differences in the Canva editor.

Canva's [supported file formats](https://www.canva.com/help/upload-formats-requirements-variantb/) include `.pptx` and list 3D objects, WordArt and pattern fills as examples of content that may not import. This deck contains no charts, 3D objects, WordArt or pattern fills. Its slide text, diagrams and table use ordinary text boxes and shapes; product screenshots and portraits are embedded PNG images.

Use the separate [speaker script and timing guide](slide-by-slide.md) while editing. The deck package contains speaker notes, but retain the guide as the source for rehearsal rather than relying on Canva to preserve those notes.

The PDF is only a visual backup. Canva imports PDF pages as images, so use the PPTX when you want editable slide objects.

This file has been structurally checked and rendered before upload. Canva's own conversion has not been run, so inspect the converted design before presenting.
